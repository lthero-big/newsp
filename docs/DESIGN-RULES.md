# News Daily 设计规则（长期有效）

所有 UI 改动都要遵守本文件；改规则先改这里，再改代码。来源：2026-10-15 至 10-17 主人的决定、git log、tests/mobile-layout.mjs。
标记：**[保留]** 长期规则 · **[已取代]** 留作历史，不再适用 · **[测]** 有自动测试守着（`node tests/mobile-layout.mjs`，publish.sh 推送前会跑）

## 1. 阅读优先（总原则）
- [保留] 可读性优先于装饰：正文 16px，宽卡片里的文字按自然高度排，图片高度有上限（v2.7、v3.4.2）。
- [保留] 页面上不出现流程术语和口癖，用读者语言写。页脚已去掉「规则管线生成」这类话（v3.4.3）。
- [保留][测] 首屏统计第二格写「15:00 新增」或「20:00 新增」（按最近一次增量），显示真实条数；为 0 时整格不出现（v3.5.3，替代「增量（待抓取）」）。
- [保留] 交互简洁、图标优先：卡片头部只放图标按钮，所有操作按钮都是圆形描边（包括 + 按钮，v3.4.6）。
- [保留·永久][测] 卡片正面底部只有三个圆形图标：♥ 点赞（多推这类）、收藏（书签图标）、＋更多。右上角是托盘图标「看过，收起」。不放星星条、不放「x/5」文字（v3.6，主人 10-17 定）。
- [保留·永久][测] ＋更多岛的顺序：少推这类（踩）· 加信息源 · 深挖 · 自由指令 ｜ 分隔线 ｜ 不感兴趣（= 删除，沿用倒计时、撤销、垃圾箱）。「少推这类」和「不感兴趣」之间必须有分隔线（v3.6）。
- [已取代] 卡片正面放评分星星（v2.x–v3.5.7）、♡ 收藏按钮（v3.6 起换成书签图标，♥ 专指点赞）。
- [保留] 宽卡片里不出现被拉长的胶囊按钮，也不放大 logo：像 logo 的图片（按颜色、宽高比和 URL 判断）永远不当大图用（v3.4.2）。

## 2. 布局
- [保留] 编辑部混排是默认布局：每个模块一张头条，旁边配小条列表和网格，加上「延伸」和偶尔的「点评」（v3.4）。
- [保留] 头条有图就用图，没有图就用大字摘要填满整栏（v3.4、v3.4b）。
- [保留·永久][测] 媒体优先排槽（v3.5.7）：每个模块的头条选「最好的媒体」——视频 > 图集 > 大图 > 无图。视频和图集永远不进侧栏小卡（mini），进下方网格时用宽卡。收起补位（reflow）用同一套规则；提升到头条的有图卡不得再被标成 `feature noimg`。图片加载失败时显示「图未加载」占位，不要浏览器灰框破图。
- [保留·永久][测] 手机（≤640px）像 X 一样排：头条之后，有图（图片 / 视频 / 图集）的卡片一律是大卡，没图的一律是小卡（一行标题 + 摘要），按原顺序单栏排列，不再有侧栏。收起补位也按这条（v3.6）。
- [保留·永久][测] 桌面「看大图」（v3.6，注意力机制）：侧栏小卡有图时，缩略图右下角有圆形放大标记，点缩略图或标记，这张卡原地展开成整栏宽的大图，再点一下收回。规则：① 每个模块同时最多一张展开，展开另一张会收回上一张；② 侧栏总高度不能超过头条（头条按自然高度算），超出就把图片高度压到刚好放下（不低于 160px，图片按原比例 contain 显示）；③ 连 160px 都放不下时，把这张卡挪到下方网格最前面当宽卡（其它小卡往上补位，不留洞）；④ 没有手动操作时，如果侧栏比头条矮 ≥140px，自动展开本模块排名最靠前的那张有图小卡，放不下就不自动展开；手动收起后这个模块不再自动展开。不看序号，不改整页布局。
- [保留][测] 手机（<640px）所有网格、所有主题都是单栏：卡片宽度 ≥ 视口宽度 − 40px，不允许横向滚动（v3.3.1、v3.4.1）。
- [保留] 手机上隐藏卡片序号 .rank（v3.4.8）。
- [保留][测] 标签不能换行变高（单个标签高度 <40px）。宽卡片里相邻元素的间距 ≤48px。
- [保留][测] 版面不留洞：网格里一张普通卡后面紧跟宽卡、或者落在最后时，让它占满整行（v3.5.2）。
- [保留][测] 首屏右栏（hero 槽位）和左栏等高（桌面），组件不能超出自己那一栏（cc4c58d、v3.5.3）。日历的艺术数字不能超出日历框（见第 5 节）。
- [保留][测] 侧栏小卡（mini）右侧留 44px，右上角的收起按钮不压缩略图（v3.5.3）。
- [保留] 模块计数条（meter）占满整行，跟着筛选结果变化（v2.2）。

## 3. 已收起（看过，收起）
- [保留·永久] 「已收起」的意思是：看过了，但不值得深挖、也不值得收藏，先收起来。这是主人主动做的「略读后打发」动作，不是普通的已读回执（主人 10-17 定）。
- [保留·永久][测] 收起和点赞 / 少推 / 收藏互不联动：这些操作都不会收起或移动卡片。已收起的卡片如果被收藏（包括在别的设备上收藏），就从已收起栏里拿出来、清掉收起标记，因为收藏说明它有价值（v3.5.5，v3.6 保留）。
- [保留·永久] 收起只管界面，不参与推荐学习（v3.6 去掉了原来 0.2 的轻度减分）。
- [保留·永久][测] 图标是「箭头落进托盘」（inline SVG，viewBox 16，线条图标，16px 显示，线宽 1.75，沿用圆形描边按钮）。按钮文字：未收起时「看过，收起」，收起后「已收起（点击放回）」。不再用 ✓（✓ 会被理解成普通已读）。
- [保留][测] 收起按钮固定在卡片右上角（absolute），所有版式都一样，离右上角 ≤48px（v3.4.7）。
- [保留] 主人视图里，还没收起的卡片，收起按钮上有一个红点（v3.4.7）。
- [保留][测] 收起后卡片进入本模块底部的「已收起 N 条」栏，后面的卡片往前补位，头条、侧栏、网格都不留空。点开这一栏是紧凑列表，点列表里的标题或它的「放回」按钮（箭头从托盘里出来），卡片飞回原位（FLIP 动画），原来的顺序不变（v3.5.2 纯 B 方案，主人 10-17 选定，长期保留）。
- [已取代] ✓ 后折叠成一行（v3.4.6）、头条卡只变暗不折叠（v3.4.6b）、头条和下一张卡互换位置（v3.4.9）、展开折叠卡就取消打勾（v3.4.7）。这些都由「已收起」栏代替（v3.5.5 前叫「已看」栏）。「展开即取消打勾」的意思保留在「点列表里的一行就放回」里。
- [保留][测] 手机上左滑超过约 70px 就收起，卡片进入已收起栏，弹出 4 秒「已收起 · 撤销」提示。从按钮或图片视频上开始的滑动不算。以后改版必须保留这个手势（主人 10-17 明确要求）。
- [保留] 不做「滑过就自动标记已读」，容易误触发（v3.4.7 评估后否决）。
- [已取代][测] 「本周看过」列表（v3.4.6）已在 v3.5.3 删除，代码一并移除；只保留每个模块的「已看」栏。
- [保留] 首屏统计第三格是「已收起」（今天收起的条数）。
- [保留][测] 主人的收起状态存到云端（D1 /api/reads），解锁后合并，写入有防抖（e88ef48）。访客的收起状态只存在本地，但效果和主人一样：卡片进「已收起」栏、后面补位，左滑也能收起，刷新后保持（10-20 修：之前访客点收起只变暗不移走）。

## 4. 点赞 / 少推 / 收藏（v3.6 起，替代评分）
- [保留·永久] 一个字段 vote 存点赞和少推：1 = 点赞（多推这类），0 = 无，-1 = 少推这类。点赞和少推互斥；点赞和收藏互相独立、不联动（D1 migration 0009，ratings.vote）。
- [保留·永久][测] 少推这类：卡片原地不动，不隐藏、不收起，弹「已记下：少推这类 · 撤销」。再点一次是取消少推。少推过的卡片，＋按钮右上角有一个灰色小点。
- [保留·永久] 推荐学习（规则，无 AI，scripts/collect/learning.py + scripts/sync-state.mjs）：点赞或收藏每条 +0.08（同一条既赞又藏只算一次），总加分上限 +30%；少推 = 0.5 的减分（收藏了的卡不算少推）；不感兴趣（删除）= 1。所有减分共用门槛：只命中具体的仓库 / 账号 / 网站，关键词和大厂官方渠道要 ≥2 条不同条目才生效，品牌词永不减分；总系数下限 0.4。已收起不参与。
- [已取代] 1–5 星评分、「x/5」文字、评分 ≥4 自动收藏（fav_auto，migration 0008）、1★/2★/3★ 的不同权重（v3.4.6–v3.5.7）。旧数据迁移：≥4★ → 点赞，1–2★ → 少推，3★ → 无；所有收藏都保留（0008 的回填分不清哪些是手动收藏的，宁可多留）；rating、fav_auto 两列只作历史，不再读写。
- [保留][测] 「合你口味」小标签只给主人看（owner-only），访客永远看不到：卡片的反馈系数 > 1 时，在来源行后面显示一个很小的爱心 + 「合你口味」，悬停提示「按你的喜好排前了：你赞过或收藏过 …… 的内容」，点名是哪个账号/仓库/关键词。不显示减分卡片的标记，不出现数字和流程术语（v3.5.6）。
- [保留][测] 「学到的偏好」在偏好与主题页 settings.html#learn（2026-10-21 晚按参考 zip 的 settings.html#learn 改版，只给主人看；旧地址 prefs.html 跳转过来）：顶部一句说明 + 「全部撤销」，三张规则卡（删除 = 1.0 · 少推 = 0.5；少推每单位 −25%、最低 ×0.4，多推每单位 +8%、最多 +30%；30 天减半、上限 2），再用「少推 / 多推」和「全部 / 来源 / 关键词」两组分段筛选。列出 learning.py 排序实际在用的键（/api/learned 读 D1，用 scripts/feedback.mjs + scripts/learned.mjs 计算，和 learning.py 有对拍测试 tests/learned.test.mjs）。每行：类型、名字、来自几次点赞/收藏/少推/删除和效果、一个例子标题、强度条（满格 = 2）、「撤销」；超过 12 行折叠成「显示全部」。撤销少推和垃圾箱的「清除」共用 penalty_overrides；撤销多推存成 `+key`，learning.py 同样认这个前缀。「已撤销」列表里可以恢复。
- [保留][测] 模型页 models.html（只给主人看，按参考 zip 的 models.html 布局，只读）：「故障切换链」一排节点（主用 → 备份 1…，顺序从 scripts/llm.py 的 PROVIDERS 读，现在是 gpt-6.1-sol → ds → grok → ds-official → xai），下面每个模型一行：序号、色块、名字、主用/备份标签、模型名、通道（只写「代理通道 A / B」「DeepSeek 官方 API」「xAI 官方 API」）、最近 N 期用了几期、调用次数和 token；默认不用的（sonnet）灰着显示。再下面是最近 7 期的明细（模型、输入/输出 token、是否用了备用链路），数据来自服务器 var/llm/*.summary.json，构建时并进 data/state/llm-usage.json。**网页里永远不放 key、key 尾号、key 的变量名和接口地址，也不能改模型**；改链路只在服务器上改。
- [保留] 「不感兴趣」删除有倒计时和撤销，撤销条始终完整可见，删掉的卡片进垃圾箱可以恢复（v2.4、396a64e）。
- [保留][测] 垃圾箱「已删除」每张卡有「永久删除」，标题行有「清空 N 条」；都用页内两步确认（按钮变红「确认永久删除？」+「取消」，Esc / 6 秒自动取消），不用浏览器原生弹窗，失败时页内提示。永久删除只是给 D1 deletions 行打 purged_at（迁移 0011），行保留、状态仍是 trashed：不会再出现在日报里，少推学习照常计算（在「学到的偏好」里管理），但从「已删除」和垃圾箱角标里消失，不能恢复（API 对恢复 / 再删除返回 409）。（10-21 晚）
- [保留][测] 收藏页默认把收藏和 ♥ 点赞过的一起列出；筛选行里的弹簧开关「同时列出 ♥ 点赞的」（参考 zip 的做法，动画移植自 design.lthero.com 的「弹簧拉伸开关」，assets/switch.js，减少动效时没有动画）关掉后只列收藏，选择记在本机（news-fav-liked）。
- [保留][测] 收藏页时间轴（2026-10-21）：「收藏时间 / 发布日期」两段切换，默认收藏时间，会记住上次的选择。卡片按天分组，每组开头是粗体日期（如「10.21」）加星期、「收藏于 / 发布于」和条数。收藏时间取 D1 的 ratings.fav_at（migration 0010；老收藏用 updated_at 回填，点赞卡用最后一次更新时间）。日历圆点跟着当前排序走。`#d=` 按当前排序选日期，`#pub=` 强制按发布日期（往期页面板的「还有 N 条收藏」用它）。
- [保留][测] 订阅源页 sources.html（按参考 zip 的 sources.html 改版）：左边按类别分栏（X、Reddit、Hacker News、RSS、RSSHub、GitHub、Hugging Face、OSSInsight，带数量），右边是该类别的说明、整体开关、分组小节和每个源一行（开关用同一个弹簧开关）；X 有账号筛选和「全部启用 / 停用」，每个分组有整组开关；「＋ 添加源」弹窗只加 X 账号、X 关键词、RSSHub 路由（Reddit / RSS 从卡片上加）。底部吸住的保存条。不做参考里的「管理」（概览、分组改名、拖动排序）和多账号。每个源行尾有「权重」小下拉（−1…+2，0 = 不加权，配置里的默认值直接显示）；改回默认就删除覆盖。存在 config.weights，下一期起作用：推荐分 × max(0.4, 1 + 0.3·权重)（10-21 加）。

## 5. 日历与日期（主人要求长期保留）
